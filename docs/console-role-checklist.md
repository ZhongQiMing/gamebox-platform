# 控制台手测（五角色 · 一步一步）

有问题马上喊我改。测完一步打勾，再测下一步。  
顺序建议：**管理员 → 房主 → 代理 → 客服 → 子账号 → 手机**。

| 端 | 地址 | 干什么 |
| --- | --- | --- |
| 后端 | http://localhost:3000/api | 接口 |
| **电脑版** | http://localhost:3001/ | 运营控制台（全功能） |
| **手机·代理/客服** | http://localhost:5173/staff/login/agent | 代理 / 子账号 / 客服 |
| **手机·房主** | http://localhost:5173/staff/login/branch | 房主 / 管理员 |

开发管理员：`admin` / `Admin@123456`  
建房时会生成**代理账号**（密码只显示一次，务必记下）。  
房主账号要在管理员「账号中心」里单独创建。  
客服账号由**管理员或房主**在房间「绑定代理」开通；**代理**侧栏「客服账号」只做划额、佣金%、接单占比，不能自己开号。

角色对照：管理员=ADMIN · 房主=BRANCH · 代理=AGENT · 客服=CS · 子账号=PROXY

## 0. 测前准备（管理员做一次）

1. 登录 http://localhost:3001/ （`admin` / `Admin@123456`）
2. **账号中心** → 建一个房主（用户名/密码自己定，记下来）
   - 期望：列表里能看到角色「房主」
3. **房间中心** → **创建房间**（先测一条线即可）
   - **A 现金盘**：月费可设；创建后给代理上下分加「上盘额度/代理余额」
   - **B 信用盘**：填信用额度+占成；月费可设（**结账摊入**，不自动扣余额）；创建后代理「剩余信用」=合同额度；**不能**给代理上下分，要用「调整信用额度」
   - 房间名随意；「可见房主」勾上刚建的房主
   - 记下：进房码、代理用户名、代理密码、盘口类型
   - 期望：列表有这个房，状态营业中，盘口标签正确
4. 进房间详情 → **绑定代理**
   - 现金：给代理买飞盘额度（如 2000）→「上盘额度」「代理余额」变大
   - 信用：点「调整信用额度」验证加减；点上下分应失败或无按钮
   - （管理员与房主同级，共用平台盘口池；**不能给房主上分，也不能直接给玩家上分**）

资金口径见 [`真分假分飞盘说明.md`](./真分假分飞盘说明.md)。  
后面步骤会反复用到：`房主账号` / `代理账号` / `进房码` /（后面管理员或房主开通的）`客服账号`。

## A. 管理员电脑（3001）

### A1. 布局 / 侧栏菜单

登录管理员后核对：

| 区域 | 期望 |
| --- | --- |
| 左侧栏 | **有**暗色侧栏 |
| 侧栏菜单 | 工作台、房间中心、报表、游戏管理、控奖、账号中心、回水规则、风控、操作日志 |
| 侧栏**没有** | 玩家中心、客服账号（代理设置页）、客服与上下分 |
| 顶栏 | 角色「管理员」；日常可不强调账户余额 |

### A2. 各页能开

1. 控奖 —— 能打开
2. 游戏管理 —— 能打开
3. 报表中心 —— 能打开
4. 风控 —— 能打开
5. 账号中心 —— 能打开（含房主 Tab）

### A3. 房间与授权

1. 房间详情 → 可见房主：能勾选/取消房主
   - 取消后：该房主登录应看不见此房（后面 B2 再验）
2. 「删除」= 关闭房间（数据保留），勾选「显示已关闭」能看见；无彻底删除
3. 能改月费、能重置代理密码、能轮换进房码（若页面有）

### A4. 开通客服（测客服前必做 · 管理员或房主二选一）

1. 房间详情 → **绑定代理** → **开客服账号**
2. 挂到本房代理；记下用户名/密码（只显示一次）
3. 期望：开通成功；划额由代理在侧栏「客服账号」做

### A5. 负向（管理员不该能干的）

1. 侧栏没有「客服与上下分 / 玩家上下分」入口（或进不去给玩家上分）
2. 房间玩家列表里找不到「给玩家上分」——正常
3. 硬调接口给玩家上分应失败（可跳过，喊我验）

## B. 房主电脑（3001）

### B1. 布局 / 菜单

1. 退出管理员，用**房主账号**登录 3001
2. 期望：

| 区域 | 期望 |
| --- | --- |
| 左侧栏 | **有**暗色侧栏 |
| 有 | 工作台、房间中心、报表、回水规则、风控、操作日志 |
| 没有 | 控奖、游戏管理、账号中心、玩家中心、客服账号、客服与上下分 |
| 顶栏 | 角色「房主」 |
| 工作台 | 与管理员同布局（必办四格 + KPI + 近 7 日趋势）；无控奖/账号中心入口，改为报表/回水 |

3. 地址栏硬开 `/games` 或 `/control` —— 应进不去或被踢回

### B2. 只看见授权房间

1. 打开房间中心 → 只看见管理员勾给自己的房
2. 若管理员在 A3 取消了授权：刷新后该房应消失

### B3. 房主建房（可选）

1. 房主自己「创建房间」
   - 期望：能建成功；**默认全部房主可见**；**不会**出现控奖配置
   - 对比：管理员建房则只有勾选的房主能看见

### B4. 给代理上分 / 回收

1. 进授权房间 → 绑定代理
2. 给代理上分（如 500）
   - 期望：代理上盘额度、代理余额增加（不扣房主自己的余额——房主没有独立金库）
3. 若有回收：收回一点
   - 期望：代理额度减少，无报错

### B5. 房主不能给玩家上分

1. 页面上不应有「玩家上下分 / 客服与上下分」菜单
2. 房间里即便有玩家列表，也不应能直接给玩家加真分

### B6. 月费 / 状态

1. 房间详情**没有**「房间彩池 / 注资」
2. 能改月费、能改房间状态（营业/维护/冻结）
3. 回水规则页：能看，**不能改**全局总返水

### B7. 房主开子账号

1. 在代理详情/绑定代理里「开子账号」（挂到该房代理下）
2. 记下子账号用户名密码
3. 期望：创建成功（后面 D 节用）

### B7b. 房主开通客服（若 A4 未做）

1. 房间详情 → 绑定代理 → **开客服账号**
2. 记下客服账号密码；期望开通成功（侧栏没有「客服账号」）

### B8. 风控

1. 点「风控」——能打开
2. 有告警时可点处理（没有告警也能打开页即可）

## C. 代理电脑（3001）

### C1. 布局 / 菜单

1. 用**建房时生成的代理账号**登录
2. 期望：

| 区域 | 期望 |
| --- | --- |
| 左侧栏 | **有**暗色侧栏 |
| 有 | 工作台、我的房间、报表、**客服与上下分**、**客服账号**、回水规则、操作日志（玩家在房间详情副项） |
| 没有 | 控奖、游戏管理、账号中心、风控 |
| 顶栏 | 角色「代理」；可见余额等 |

3. 点「我的房间」：只有一间时应**直接进房间详情**
4. **工作台**顺序：额度与账户 → 待审 → 今日佣金与注单 → 本房输赢与上下分；快捷「我的房间」

### C2. 房间详情数字（按盘口）

**现金盘**

| 名称 | 大致含义 |
| --- | --- |
| 上盘额度 | 向平台买的飞盘额度 |
| 上盘可飞 | min(余额,上盘额度)；到 0 软关盘 |
| 代理余额 | 代理账户余额（月费从这里扣） |
| 玩家余额 | 本房玩家当前余额合计 |

**信用盘**

| 名称 | 大致含义 |
| --- | --- |
| 合同额度 | 本房信用合同上限 |
| 剩余信用 | 还能给玩家上分的额度 |
| 客服额度 / 玩家余额 | 计入信用账本合计 |
| 佣金账户 | 飞盘流水工资；结账轧差后清零 |
| 飞盘 | 只看开关：开=平台；关=跟代理 |

（代理顶栏：现金见上盘额度/上盘可飞；信用见「剩余信用」「佣金账户」。管理员/房主按房间详情信用账本或代理额度条操作。）

### C2b. 经营概况（代理视角）

1. 打开经营概况
2. 期望区块齐全：我的佣金、本房输赢、玩家上下分、注单明细、最近注单、最近上下分
3. 不应再只有管理员那套「净盈亏」当唯一头牌

### C3. 代理给玩家上分（主职）

1. 先让玩家用 App/大厅进房（进房码），或用已有测试玩家
2. 在房间详情「玩家」副项给玩家上分（如 100）
   - 现金：玩家持分加；上盘额度不变
   - 信用：玩家余额加；**剩余信用减**；不能超过剩余
3. 再测下分：玩家余额减；现金回额度/占用，信用买回剩余信用

### C4. 飞盘 / 玩家回水（仅代理）

1. 玩家列表关掉/打开飞盘
2. 能改玩家回水比例（若入口在）

### C4b. 报表中心（代理视角）

1. 打开侧栏「报表中心」
2. 头牌是**我的佣金**；文案用「本房盈亏 / 玩家盈亏」

### C5. 代理边界

1. **不能**把房间设为「已关闭」
2. **不能**进风控 / 控奖 / 游戏管理
3. **不能**给自己「卖额度」（额度来自管理员/房主）

### C6. 代理对子账号的权限

1. 绑定代理页：**不应出现**「开子账号」
2. 子账号由管理员/房主在 B7 开通
3. 代理对已有子账号：**只能改名字**、设值班；**不能**重置密码、不能停用/启用

### C7. 客服与上下分（代理视角）

1. 打开「客服与上下分」
2. 期望布局：**三栏**（会话名单 · 聊天 · **右侧审核队列**）
3. 有「昨日流水」Tab；聊天顶栏可有「发早茶」
4. 右侧审核：全部 / 该玩家；通过 / 拒绝可用

### C8. 客服账号（代理设置 · 测客服前必做）

1. 打开侧栏「客服账号」（仅代理有此入口）
2. **没有**「开客服」按钮（开号在房间「绑定代理」，见 A4 / B7b）
3. 卡片上测按钮：
   - **上分**：从代理额度划给客服
   - **下分**：从客服额度收回
   - **佣金**：设置佣金比例
   - **占比**：接单权重（多客服时合计约 100%）
4. 期望：列表能看到客服；额度数字对得上

## D. 子账号电脑（3001）

用 B7 建的子账号登录。

5. 无风控 / 控奖 / 游戏管理
