# 聊天房彩票 · 全部玩法可口令清单（文件 4）

> 用途：你按此清单逐条手测下注。  
> 格式：统一 `玩法/金额`（六合另支持空格金额、`各`）。金额例：`100`；时时彩/快三/赛车另支持 `梭哈`。  
> 来源：各游戏 H5 `parsePlay` + 展开层（`expandPlayPart` / `expandChatBetInput`）。

---

## 1. 快乐时时彩 `ssc` / 1分时时彩 `ffc`（口令相同）

### 1.1 直接口令（parsePlay）

| 玩法 | 口令模板 | 示例 |
|------|----------|------|
| 总和两面 | `[总和\|总]?大/小/单/双` | `大/100` `总和单/50` |
| 定位两面 | `万\|千\|百\|十\|个` + `大/小/单/双` | `万单/50` `个双/100` |
| 定位胆 | `万\|千\|百\|十\|个` + `0-9` | `万5/100` `个0/50` |
| 前中后形态 | `前三\|中三\|后三` + `豹子\|顺子\|对子\|半顺\|杂六` | `前三豹子/100` |
| 组三 | `前三\|中三\|后三` + `组三` + 两不同码 | `前三组三13/80` |
| 组六 | `前三\|中三\|后三` + `组六` + 三不同码 | `后三组六258/50` |
| 不定位 | `前三\|中三\|后三` + 一位数 | `前三3/100` |
| 龙虎和 | `龙` `虎` `和` | `龙/100` |
| 斗牛 | `无牛` `牛牛` `牛1`…`牛9` | `牛5/50` |
| 牛两面 | `牛大` `牛小` `牛单` `牛双` | `牛大/100` |

### 1.2 展开口令（expand → 多注）

| 写法 | 展开为 | 示例 |
|------|--------|------|
| 多位两面 | 每位一面 | `万千单/100` → 万单、千单 |
| 多位多号 | 位×号 | `十百59/100` → 十5 十9 百5 百9 |
| 形态组合 | 段×形态 | `前三中三豹子顺子/100` |
| 组三复式 | C(n,2) | `前三组三012/50` |
| 组六复式 | C(n,3) | `前三组六012345/50` |
| 不定位复式 | 每位号一注 | `前三012/50` |
| 牛多码 | 多个牛几 | `牛123/50` |
| `牛` | → 牛牛 | `牛/100` |

### 1.3 金额
- `玩法/数字` 或（部分玩法）无斜杠贴金额  
- `玩法/梭哈`（全下/均分）  
- 空格多注：`大/100 万单/50`

## 2. 1分快三 `kuai3`

### 2.1 直接口令

| 玩法 | 口令模板 | 示例 |
|------|----------|------|
| 和值两面 | `大` `小` `单` `双` | `大/100` |
| 和值点 | `和`/`和值` + 4–17 | `和10/50` `和值17/100` |
| 三军/独 | `三军1-6` `独1-6` | `三军3/50` |
| 二同 | `二同`/`二同号` + 1–6 | `二同3/50` `二同号5/50` |
| 指定三同 | `三同`/`三同号` + 1–6 | `三同6/100` |
| 任意豹子 | `三同` `三同号` `豹子` `豹` | `三同号/100` |
| 指定三连 | `三连` + 连续三码 | `三连234/80` |
| 任意三连 | `三连号` `顺子` `三连` | `三连号/100` |
| 三不同 | `三不同号` `三不同` `杂六` | `三不同号/100` |
| 长牌 | `长牌` + 两不同码(1-6) | `长牌12/100` |

### 2.2 展开口令
- `大小/100` → 大、小（真人可对冲；机器人生成器不会出）  
- `和4/7/10/100` 或 `和4 7 10/100` → 和4、和7、和10  
- `三军35/50` → 三军3、三军5  
- `二同13/50` → 二同1、二同3  
- `长牌124/50` → 长牌12、13、14、24…  

### 2.3 金额
同 SSC：`/`、梭哈、空格多注。带号玩法（三军/二同/独/长牌/三连码）金额须 `/`。

## 3. 幸运六合彩 `lhc`

### 3.1 标准口令（parsePlay）

| 玩法 | 口令模板 | 示例 |
|------|----------|------|
| 特码号 | `特码`/`特` + 01–49 | `特码08/100` |
| 正码号 | `正码`/`正` + 01–49 | `正码15/50` |
| 特码两面 | `特码`/`特` + 大/小/单/双；裸两面同义 | `特码大/50` `大/50` |
| 特码组合 | `特码`/`特` + 大单/大双/小单/小双 | `特码大单/50` |
| 合数 | `合`/`特合` + 大/小/单/双 | `合单/50` |
| 特尾 | `尾`/`特尾` + 大/小 | `尾大/50` |
| 色波 | `红波` `蓝波` `绿波` | `红波/100` |
| 总和 | `总和`/`总` + 大/小/单/双 | `总和大/50` |
| 总尾 | `总尾大` `总尾小` | `总尾大/50` |
| 总数项·尾 | `[平特]?N尾` | `0尾/50` `3尾/50` |
| 尾不中 | `[平特]?N尾不中` | `5尾不中/50` |
| **总肖项 = 一肖** | `一肖`/`平特` + 生肖；或裸生肖（同义） | `一肖鼠/50` `平特鼠/50` `鼠/50` |
| 生肖连 | `复式`/`拖头` + 二～五肖中/不中 + 生肖 | `复式二肖中鼠,牛/50` |
| 尾数连 | `复式`/`拖头` + 二～四尾中/不中 | `复式二尾中0尾,1尾/50` |
| 六肖 | `六肖中`/`六肖不中` + 恰6肖 | `六肖中鼠牛虎兔龙蛇/50` |
| 连码 | `复式`/`拖头`/对碰等 + 二全中… + 号码 | `复式二全中01,08/50` `拖头二全中01,08,15/50` |
| 不中 | `复式` + 五～十二不中 + 号码 | `复式五不中01,02,03,04,05/50` |

> **已删除特肖**：不再提供特肖面板/口令（赔率约 12，易误解）。总肖项只保留一肖（七码任一，赔率约 2）。

### 3.2 简口令（expandChatBetInput → 标准）

| 简写 | 变成 | 示例 |
|------|------|------|
| 裸两面 | 特码两面 | `大/100` → 特码大 |
| 裸组合 | 特码组合 | `大单/50` |
| `大各100` | 该属性下每个特码号各一注 | |
| `0尾各50` | 该尾特码号各一注 | |
| `19,31/10` | 多个特码号 | |
| `一肖`/`平特` 多肖 | 各一肖一注 | `平特猪蛇/100` → 一肖猪、一肖蛇 |
| 生肖连简写 | 复式N肖中… | `猪猴二连50` 等 |

### 3.3 金额
- `玩法/金额`、`玩法 金额`、部分胶连  
- **支持 `各`**；**不支持梭哈**  
- 多注可用 `；` / 换行  
- 真人对冲（如 `特码大/50 特码小/50`）**允许**；机器人生成器禁止

## 4. 北京赛车 `bjsc` / 极速赛车 `speed-racing` / 幸运飞艇 `speed-boat`（口令相同）

> 数字约定：赛道/车号 `0` = 第10道/10号；`1`–`9` = 1–9。  
> **定位统一写 `赛道/车号`，不要写「定」**（旧 `1定5` 仍兼容解析，面板与机器人只出 `/`）。  
> 展示/口令用赛道数字，不写冠军/亚军。

### 4.1 直接口令

| 玩法 | 口令模板 | 示例 |
|------|----------|------|
| 冠亚两面 | `冠亚` + 大/小/单/双 | `冠亚大/100` |
| 冠亚和值 | `冠亚和` + 3–19 | `冠亚和11/100` |
| 赛道两面 | `0-9` + 大/小/单/双 | `1单/50` `0大/50` |
| 赛道定位 | `0-9` + `/` + `0-9`/`10` | `1/5/100` `0/3/50` |
| 龙虎组 | `1-5` + 龙/虎 | `1龙/50` `5虎/50` |
| 裸龙虎 | `龙` `虎`（=1道对0道） | `龙/50` |
| 裸两面 | `大/小/单/双`（默认1道） | `大/100` |

### 4.2 展开口令

| 写法 | 展开 | 示例 |
|------|------|------|
| 多赛道两面 | 各道一面 | `123单/100` |
| 多赛道定位 | 道×号 | `12/35/100` → 1/3 1/5 2/3 2/5 |
| 冠亚和多选 | 各和值一注 | `冠亚和3/5/12/100` |
| 多组龙虎 | | `12龙/50` |
| 仅号码（默认1道） | 1道定号 | `35/100` → 1/3 1/5 |

### 4.3 金额
- **必须** `玩法/金额`（不可无斜杠胶连金额）  
- 支持梭哈；空格多注

## 手测建议顺序
1. 每个游戏先测「示例占位符」那 2～3 条  
2. 再按上表每类玩法至少 1 条  
3. 六合重点测：`一肖鼠/50`、`平特鼠/50`（应同义）、确认特肖已不可下  
4. 封盘后再试 1 条，应被拒绝  
5. 开奖后看注单核对 / 中奖核对文案是否与你下的口令一致
