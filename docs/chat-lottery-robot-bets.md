# 聊天房彩票 · 机器人可下注明细（文件 3）

> 来源：`server/src/modules/rooms/room-chat-atmosphere.ts`  
> 发送格式：一律 `玩法/金额`，金额从 `{20,30,50,80,100,150,200,300,500}` 抽取；每次 1～2 注。  
> **硬规则：** 同条消息不对冲（大/小、单/双、龙/虎）；真人对冲不禁，机器人禁。  
> 请你按本表核对「像不像真人」「有没有不该出现的口令」；有问题当场改。

| --- | --------------------------- | ---------------------- |

| 10% | **总肖项 = 一肖**：`一肖`+生肖（可空格多肖） | `一肖鼠/50` `一肖鼠 一肖牛/100` |

## 机器人下注时间规则（对照检查用）

- 仅在该游戏「可下注」期：`PENDING` 且未封盘  
- 封盘 / 应开未开 → 整游戏暂停氛围注  
- 按房/按游戏机器人数后续由代理页配置；当前生成器只负责合法口令

## 请你现场改的时候重点盯

1. 有没有看不懂 / 不像真人的口令
2. 有没有「玩法清单里根本没有」的口令
3. 六合总肖是否一律像 `一肖鼠/金额`（不要再出现特肖）
4. 有没有机器人同条大1+小这种对冲
5. 赛车是否还残留「定」或名次中文
