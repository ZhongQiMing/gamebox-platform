# V66 幸运六合彩官方玩法规则摘录

来源：游客登录盘面「游戏规则」弹窗全文（2026-08-01 抓取）

## 左侧导航（顺序）

特码 → 特码两面 → 特码色波 → 特码生肖 → 正码 → 正码特 → 正码1~6 → 正波 → 平特一肖 → 平特尾数 → 连肖 → 连尾 → 连码 → 总和两面 → 特码头尾数 → 特码合肖 → 五行 → 正肖 → 自选不中

## 核心差异要点（相对本仓库旧实现）

1. **特码 49 和局**：两面/形态/合数/尾数/半波/半半波/合肖、正码位两面等，开 49 退本。
2. **总和**：只用**前六个正码**；总和大 ≥150，总和小 ≤149（不是七码 175）。
3. **正肖**：同肖出现多个正码时**派彩倍增**。
4. **生肖**：按当年本命轮换；马年本命马含 01/13/25/37/49。
5. **游戏规则**：居中弹窗，标题=当前玩法，只显示该玩法条文。

## 规则全文（按玩法）

### 特码

从49个号码中选择1个号码，所选号码与开奖的特码相同，即中奖。

投注【01】；开奖号码：*,*,*,*,*,*,01，特码为01，即中奖。

### 特码两面

选择1个形态(大:25-48；小:01-24；单:个位数1,3,5,7,9；双:个位数0,2,4,6,8)，与开奖号码中特码的形态相同，即中奖。开出特码49时为和局，退还本金。

### 特码形态（大单等）

通过大小单双组合产生大单/小单/大双/小双。开出特码49时为和局，退还本金。

### 特码合数 / 特码尾数

合大≥7、合小≤6；尾大5~9、尾小0~4。开出特码49时为和局，退还本金。

### 总和两面

与当期开出的**前六个号码**总和形态相同即中奖。总和大≥150；总和小≤149。

### 总和尾数

以**前六个号码**总和个位数判断总尾大/小。

### 特码头尾数

头=十位0~4；尾=个位0~9。

### 特码色波 / 半波 / 半半波

色波划分同港彩；半波/半半波开49和局退本。

### 特码生肖

用十二生肖当年的年龄对应1~49；特码落在所选生肖号码内即中。

### 特码合肖

选2~11个生肖；特码生肖在组合内即中。开出特码49时为和局，退还本金。

### 五行

选择1个五行属性，特码在该属性号码范围内即中。

### 正码 / 正码特 / 正码1~6 / 正波

正码=前六码；正码特按位对号；正码1~6两面/形态/合数/尾数开49和局；正波按位色波。

### 正肖

前6个正码（不含特码）任一落在生肖范围内即中；超过1个正码落在同肖则派彩倍增。

### 平特一肖 / 平特尾数

七码含该肖/尾即中，只派一次。

### 自选不中

选5~12个号，七码均不在组合内即中。

### 连肖 / 连尾 / 连码

见官方条文；连肖含本命取本命赔率；连尾含0尾取0尾赔率。
