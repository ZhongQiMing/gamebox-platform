## 3. 代理 `AGENT`

| # | 操作 | 期望 | 结果 |
|---|------|------|------|
| 3.1 | 登录 | 侧栏有房间/玩家上下分/报表/审核等；无控奖/游戏管理 | ☐ 对 ☐ 不对 ☐ 不懂 |
| 3.2 | 进本房「绑定代理」 | 见可发额度 / 飞盘占用 / 余额 / 已发（点 ? 有说明） | ☐ 对 ☐ 不对 ☐ 不懂 |
| 3.3 | 玩家上分 | 玩家余额加；可发额度减；飞盘占用升（有真分发出时） | ☐ 对 ☐ 不对 ☐ 不懂 |
| 3.4 | 玩家下分 | 反向；数字与流水对得上 | ☐ 对 ☐ 不对 ☐ 不懂 |
| 3.5 | 开子账号 | 弹出**一次**密码可复制；列表出现 PROXY | ☐ 对 ☐ 不对 ☐ 不懂 |
| 3.6 | 设值班 | 可选子账号值班 | ☐ 对 ☐ 不对 ☐ 不懂 |
| 3.7 | 改房间状态 | 代理可以；确认后列表状态变 | ☐ 对 ☐ 不对 ☐ 不懂 |

**数字含义（对照用，详见 [`真分假分飞盘说明.md`](./真分假分飞盘说明.md)）**

- **可发额度**：还能给玩家发多少真分  
- **飞盘占用**：已发给玩家、还在「桌上」参与飞盘暴露的量；到 0 会关飞盘  
- **余额**：代理自己口袋（月费、关盘输赢、返水等）；**不是**玩家余额  
- 玩家下注：先扣**玩家**余额；飞盘开时对手盘是房间池，关盘时是代理账
