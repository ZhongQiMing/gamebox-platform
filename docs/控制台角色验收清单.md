# 运营控制台 · 四角色手测验收

> 用法：本地或测试库起 `server` + `admin-panel`，用四套账号逐项勾选。  
> 期望行为已按当前代码核对（`admin-panel` 路由/房间详情权限 + `/console` API）。  
> **盘口分叉**：建房选 A 现金盘 / B 信用盘，代理侧数字口径不同，见 [`真分假分飞盘说明.md`](./真分假分飞盘说明.md)。

默认管理员（仅开发 seed）：`admin` / `Admin@123456`  
生产禁止用默认弱口令；见 `server/prisma/seed.ts` 与 `SEED_ADMIN_PASSWORD`。

## 5. 手机 staff（抽测）

入口：玩家端 `/staff/login/agent` 或 `/staff/login/branch`  
两端分工总表见 [`BV两端与手机电脑能力对照.md`](./BV两端与手机电脑能力对照.md)。

### 5.1 管理员 / 房主（手机 = 急办）

- [ ] 首页：今日盈亏 + 待办（风控）+ 快操作（房间 / 代理）  
- [ ] 信用房进房间：可「调整信用额度」；现金房可代理上下分  
- [ ] 无「操作日志」入口；游戏 / 控奖 / 回水仅提示请用电脑  

### 5.2 代理

- [ ] 底栏：游戏 | 充值 | 明细 | 客服 | 我的  
- [ ] 信用口径脚注 / 上盘查询文案正确  
- [ ] 客服聊天「审本单」、下级挂靠、申请审核可用  

### 5.3 客服（手机）

入口：玩家端菜单 →「代理登录」→ `/staff/login/agent`（与代理同入口，账号角色为 CS）

- [ ] 客服账号可登录；落地「上下分审核」  
- [ ] 底栏：审核 | 明细 | 客服 | 我的（无游戏；与「我的」入口不重复）  
- [ ] 明细三 Tab：余额 / 上下分 / 佣金（仅入账记录，笔结进额度）  
- [ ] 「我的」：只显示一份可用额度 + 接单开关 + 佣金记录入口；账户/改密  
- [ ] 审核页「已通过」可看本人审过的上下分  
- [ ] 可审上下分申请；会话内「审本单 / 审申请」可用  
- [ ] 可回复玩家客服消息；不可进玩家列表上下分、不可进游戏大厅
