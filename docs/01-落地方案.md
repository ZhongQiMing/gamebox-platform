# 落地方案

> 总纲见 [`00-最优架构方案.md`](./00-最优架构方案.md)。本文聚焦目录、迁移与部署。

## 目录结构（项目根）

```text
gamebox-platform/
├── package.json / pnpm-workspace.yaml / .gitignore / …
├── server/                      # NestJS 后端（账本 / 鉴权 / console 运营 API）
├── packages/shared/             # 多端共享类型与赔付表
├── client-app/                  # 玩家端 Vue3 + Capacitor；含手机 staff（管理急办 / 代理待办另开，见 docs/BV两端与手机电脑能力对照.md）
├── admin-panel/                 # PC 运营控制台（ADMIN/BRANCH/AGENT/PROXY）
├── games-assets/                # 静态 H5 小游戏（iframe 接入）
├── scripts/                     # 部署 / 探活 / 备份 / 字体等工具
└── docs/                        # 方案与验收文档
```

> **三端分工（已落地）**：PC `admin-panel` 全量运营；手机 `client-app/staff` 轻量上下分；玩家端推广中心只看佣金/团队。  
> 角色验收见 [`控制台角色验收清单.md`](./控制台角色验收清单.md)；资金概念见 [`真分假分飞盘说明.md`](./真分假分飞盘说明.md)；全局软控见 [`全局软控说明.md`](./全局软控说明.md)。

## 原型逻辑去向
| 原型 | 去向 |
|------|------|
| 账号校验 / 金额格式化 | `packages/shared` |
| 积分/爆率/开奖/分润/审核（权威） | **server** |
| toast / 弹窗 / tabbar / 音效 | client-app 全局组件 |
| 页面交互 | client-app `views/*.vue` |
| localStorage / mock 数据 | client-app `services` + `stores`，改调 server |

## 阶段一部署（单机）
Nginx 统一入口：`/api`→server、`/ws`→WS、`/admin`→admin-panel、`/games`→games-assets、`/download`→APK 页；PG + Redis 同机。
约束：server 无状态、域名配置化 → 将来可平滑拆分/上 CDN。

## 开发顺序（里程碑）
M0 脚手架 → M1 后端地基(账本/鉴权) → M2 APP 连后端样板 → M3 出 APK → M4 资金+一款游戏闭环 → M5 后台 → M6 补全(多游戏/活动/客服) → M7 上线。详见 `05`。
