# 现金盘 / 信用盘 · 速查

完整说明见 [`真分假分飞盘说明.md`](./真分假分飞盘说明.md)。

## 角色口径

- **管理员 / 房主**：同级，共用平台盘口池。  
  - 现金盘：给代理买盘分额度（余额+上盘额度）。  
  - 信用盘：调整信用额度；不能给信用代理「买额度式」上下分。  
- **代理 / 子账号**：给玩家上下分（盘分 ↔ 玩家）；额度在主代理账上。

## 一眼对照

| | A 现金盘 | B 信用盘 |
|--|----------|----------|
| 给代理加款 | 买盘分：余额+上盘额度 | 调整信用额度（先赊） |
| 玩家上分 | 扣盘分 → 加玩家（可负） | 同左 |
| 玩家下分 | 扣玩家 → 加回盘分 | 同左 |
| 飞盘开条件 | 开关开且可飞≥本注；不足关盘坐庄 | 同左 |
| 飞盘净输赢 | **不改盘分**（只动玩家↔平台） | 同左 |
| 关盘 | 下注进盘分、派彩出盘分 | 同左 |
| 佣金袋 | 进/出盘分 | A 进佣金账户；付玩家/挂靠从盘分 |
| 超分 | 盘分变负 | 同左 |
