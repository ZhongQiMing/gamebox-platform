# 全局软控说明（运营 + 技术）

> **入口**：管理后台 → 控奖中心（仅管理员）。  
> **定位**：用「上海自然日日账 + 软偏置」轻轻把共盘结果往目标带靠；**不是**旧硬控逐房间强开指定结果。  
> **旧硬控** `ControlPolicy` 已停用，勿再依赖。

资金/飞盘概念见 [`真分假分飞盘说明.md`](./真分假分飞盘说明.md)。

# 一、运营版（忘记时看这里）

## 1. 两套账，别混

| 账 | 范围 | 干什么 |
|----|------|--------|
| **共盘日账** | 彩票 + 牌桌（上海自然日） | 定调控档（IDLE/STEER/BOOST/HALT），挑号往中轴靠 |
| **街机资金池** | 水果机、奔驰宝马、电子等 | **每个游戏一口长期池**，盯池余额贴近目标留存；**不进共盘日账** |

- 房间/玩家**偏置只作用于彩票/牌桌**，不进街机池。  
- **控后冷却已停用**（冷却期会把防爆权让出去，刚好撞上爆赔只能认赔）。

## 1.5 单期总账（最重要的一层）

软控**不认玩法**。几百人、几千种玩法穷举不完，写玩法级白名单只会越补越乱。
每期开奖只看三个数：**本期总注 F**、某候选的**总派彩 C**、**有效人数**。

判定顺序：

1. **自然结果庄家亏 ≤ 50% → 一号不挑。**  
   买 9 个号漏 1 个、买 8 个漏 2 个这类覆盖打法，中了也只亏一成两成，
   **根本进不了软控**，不会出现「你缺哪个就开哪个」。
2. 亏超 50% → 介入，在「亏不过 50%」的候选里朝**亏 30%** 靠；分接近时**优先赢家人数多**的候选。
3. 若只剩「通杀」候选（庄家赢走 ≥80% 流水），再过金额门：

| 情况 | 结果 |
|------|------|
| 自然亏损 < 5000 元 | 认赔，不通杀 |
| 人数 < 5 或本期总注 < 5000 元 | **小盘保护**，不通杀 |
| 自然亏损 < 10000 元 | 认赔 |
| 近 48 小时该游戏盈利 < 10000 元 | 不硬追，认赔 |
| 自然亏损 ≤ 周期盈利 × 20% | 已经赚够，认赔 |
| 以上都不满足 | 才允许通杀（防爆） |

没有合法候选 → **回退自然开奖**（认赔）。

## 1.6 慢性失血档位（每期小亏，累成大亏）

单期只防爆，挡不住「每期亏四成」这种温水煮青蛙。加一层按游戏独立的
**48 小时周期账**，它不直接挑号，只收紧上面那层的门槛：

| 档位 | 触发（48h 净留存 R） | 开档线 | 目标 | 认赔门 / 防爆门 |
|------|---------------------|--------|------|----------------|
| 正常 | R ≥ −5% | 亏 50% | 亏 30% | 5000 / 10000 |
| 回收 | R < −10% | 亏 30% | 持平 | 3000 / 5000 |
| 强回收 | R < −25% | 亏 15% | 庄赢 10% | 2000 / 3000 |

- **滞回**：进档看 −10% / −25%，退档要回到 −5% 以上，避免一天来回跳。  
- **样本门**：48 小时流水不足 5 万不进回收档，别把小盘收死。  
- **小盘保护照旧**：任何档位下，人少或本期总注小都不许通杀。  
- 后台开关三态：`自动 / 强制正常 / 强制回收`。

最狠也只到「庄赢 10%」为止，**实在还输就认**，不会为了追亏无限拧号。

## 2. 日账四个数（界面「当日实绩」）

| 符号 | 含义 | 怎么算 |
|------|------|--------|
| **F** | 当日流水 | 有效投注合计 |
| **G** | 庄家盈亏 | 流水 − 派彩（正=庄赢） |
| **C** | 代理佣金（估算） | 跟「回水规则 → 回水总额」同步，界面只读 |
| **R** | 日净利率 | `(G − C) ÷ F` |

对照中轴时还会看：

- **目标庄家盈亏** ≈ `F × 中轴% + C`  
- **相对中轴盈亏** = 实际 G − 目标（多赢 / 少赢）

## 3. 调控档（模式）

达到**开盘流水门槛**之后，按当日 **R** 定档（未达标：强制自然，偏置也不挑）：

| 模式 | 条件（人话） | 行为 |
|------|--------------|------|
| **OFF** | 总开关关 | 全自然 |
| **IDLE** | R 在目标带内 | 日账不主控；有偏置时仍可挑号（偏置次级） |
| **STEER** | R 低于目标带下限（但仍 ≥ 0） | 轻度往中轴拉 |
| **BOOST** | R &lt; 0 | 加强往中轴拉 |
| **HALT** | R 高于目标带上限 | 过热回拉（往中轴压） |

**小时锁定（重要）**：

- 界面上的 **F / G / C / R**：**刷新就现算**。  
- **调控档**：约每个**上海整点小时**用库账重核一次并锁住本小时，避免有人刷分把档位抖来抖去。  
- 卡片上会写「档位 `日期 小时`（上海）· 整点重核」。

## 4. 你常调的参数（默认值）

改参数需**管理员密码解锁**；中轴必须落在目标带内（下限 ≤ 中轴 ≤ 上限）。

| 参数 | 默认 | 说明 |
|------|------|------|
| 开盘流水门槛 | 5 万 | 未达：日账层与偏置不参与（**单期防爆仍在岗**） |
| 目标中轴 R* | 4% | 挑号往这个净利率靠 |
| 目标带 | 2%～6% | 定 IDLE / STEER / HALT |
| **单期亏损开档线** | **50%** | 自然亏超此值才挑号；候选亏超此值判非法 |
| 单期吃水上限 | 40% | **已停用**，保留字段兼容（庄家赢多少不由单期管） |
| 轻微试号 | 8 | STEER / IDLE+偏置；**仅共盘** |
| 偏热试号 | 16 | HALT |
| 加强试号 | 20 | BOOST |
| 单人缓刹 | 开 / 4 倍 | 某房玩家「净赢 ≥ 净上分×倍数」时优先压其派彩 |
| 街机目标返还率 | 0.92 | 池目标留存 = 窗口流水 × (1−返还率) |
| 街机试号 | 3 | 街机专用，改共盘试号不影响街机 |
| 街机池统计窗口 | 14 天 | 窗口外盈亏永久落袋，不再被挑号吐回 |
| 失血档位 | 自动 | 自动 / 强制正常 / 强制回收 |

开档线之外的软着陆目标、金额门、小盘门都是**代码常量**（见 `control.constants.ts`
的 `PERIOD_GUARD_BASE`），刻意不做成一堆后台可调项——参数越多越补不完。

## 5. 为什么取消控后冷却

冷却原本是防「连着几期都拧号」。但它是**下一期绝对不动**：
上一期刚拧过，下一期恰好来一发四全中，就只能眼睁睁认赔。

现在改用**单期金额门**限制干预频率：小额认赔、小盘不杀、周期赚够也认赔。
干预本来就少，不需要再让出一期防爆权。

`cooldownEnabled` 字段与 Redis key 仍在（默认关），只为兼容旧数据。

## 6. 偏置策略（房间 / 玩家）

四种（金额制，达标自动停）：

| 类型 | 含义 |
|------|------|
| 房间回血 | 该房庄家累计净赢满目标金额 → 停 |
| 房间放水 | 该房庄家累计净亏满目标金额 → 停 |
| 玩家偏赢 | 该房该玩家累计净赢满额 → 停 |
| 玩家偏输 | 该房该玩家累计净输满额 → 停 |

注意：

- 只吃**带 `fly.roomId` 的彩票/牌桌注**（现行下注必带房间）。  
- **IDLE** 时：只按偏置挑，**不跑日账中轴主控**。  
- STEER/BOOST/HALT 时：日账优先，偏置次级。  
- **启用中最多 10 条**：新建或再开时超限会直接拒绝；界面显示「启用中 x/10」。  
  达标停用后可删旧条腾位子。

## 7. 街机池（运营一眼）

- 一游戏一口池，**只统计最近 N 天**（默认 14）。  
- 余额 = 窗口内流水 − 窗口内派彩。  
- 软控把结果往「目标余额」靠（由目标返还率推出）。  
- 与房间偏置、共盘冷却无关。

为什么要窗口：早先是全历史累计，等于把平台上个月赚到的钱记成负债，之后的开奖会一路吐回去。
加窗口后，掉出窗口的盈亏永久入账，调控只对最近这段流水负责。

调窗口天数会改变「目标余额」：窗口越短越贴近当下，但低流水游戏样本太少会让调控发飘。

## 8. 运营速查：出问题先看哪

| 现象 | 先查 |
|------|------|
| 一直自然、不调控 | 总开关？本期亏损没过开档线（<50%）就是**正常不介入** |
| 玩家说「我漏买的号老是开」 | 覆盖打法亏损比例低，开档=0%；看开奖日志 `steer=false` |
| 爆赔没挡住 | 看日志 `why=`：小额认赔 / 小盘保护 / 周期已赚够，都是按规则认的 |
| 档位和数字对不上 | 日账数字刷新现算，调控档整点锁；失血档位按 48 小时算 |
| 偏置进度不涨 | 是否彩票/牌桌？是否已停用/达标？启用是否已满 10 条？ |
| 过热却越控越热 | 中轴是否在目标带外（现已禁止保存） |
| 街机和日账对不上 | 正常：两套账 |

开奖日志一行看懂：`steer`（有没有介入）、`wipeout`（准不准通杀）、
`why`（不通杀的原因）、`winners`（选中候选的赢家人数）、`gear`（失血档位）。

# 二、技术版

## 1. 关键落位

| 职责 | 位置 |
|------|------|

| 单期决策 + 挑号评分 | `server/src/modules/console/control-pick.util.ts` |
| 游戏名单、单期门槛常量、档位阈值 | `server/src/modules/console/control.constants.ts` |
| 单期规则单测（含 9 盖 1 / 8 盖 2） | `server/src/modules/console/control-pick.period.spec.ts` |
| 行为仿真 | `pnpm audit:rtp control` |
| 彩票开奖接入 | `lottery.service.ts`（`getDrawRuntime` / `commitSoftDraw` / `applySoftBiasProgress`） |
| 牌桌开奖接入 | `table.service.ts`（同上） |
| 街机池挑号 | `fruit-machine-engine` / `bcbm-engine` / `slot-engine` + `pickSeedForArcadePool` |
| 管理端 | `admin-panel/src/views/ControlView.vue`、`api/console.ts` |
| 表 | `GlobalSoftControl`、`GlobalSoftBias`；迁移含 arcade RTP、cooldown、halt tries 等 |

## 2. Redis

| Key | 用途 |
|-----|------|
| `gsc:mode:YYYY-MM-DD:HH` | 上海整点小时调控档缓存；TTL 到下一整点 |
| `gsc:cycle:<gameCode>` | 该游戏 48 小时周期账；TTL 60 秒 |
| `gsc:gear:<gameCode>` | 失血档位滞回状态；TTL 1 小时 |
| `gsc:cooldown:<gameCode>` | 旧控后冷却（已停用） |

读失败原则：

- **不得阻断开奖**。  
- 模式缓存读失败 → 展示可即时算档；开奖侧 `needPick=false`（防半残）。  
- 写失败不抛。

## 3. 开奖运行时要点（共盘）

`getDrawRuntime` 产出：

- `needPick = enabled && redisOk`。**不再**看模式、开盘门槛、冷却——
  单期防爆必须一直在岗，「这期动不动」由 `decidePeriodGuard` 按本期总账判。  
- `daySteer`：仅 STEER/BOOST/HALT 且已过开盘门槛；IDLE 只偏置。  
- `gear` / `cycleProfit` / `periodGuard`：失血档位与该档的单期门槛参数。  
- `tries`：BOOST → `candidateTriesBoost`；HALT → `candidateTriesHalt`；其余 → `candidateTries`。

挑号主循环（`lottery.service.ts` / `table.service.ts` 同构）：

1. 估自然派彩 → `decidePeriodGuard`；`steer=false` 且无偏置无缓刹 → 直接自然返回。  
2. 逐候选算**每注**派彩，一趟同时得出总派彩、分房账、分人账、赢家人数。  
3. `periodCandidateLegal` 过滤：亏过开档线一律弃；未授权通杀时，
   派彩 ≤ 20%×F 的候选也弃。  
4. 排序 `isBetterSoftGlobalPick`：缓刹 → 单期分（差 5% 内算平手，看赢家人数）
   → 日账 → 偏置。  
5. 无合法候选 → 回退自然。

缓刹：按 `${roomId}|${playerId}`，碰线时 `brakeFirst` 优先压碰线玩家合计派彩，仍先过单期过滤。

## 4. 街机池要点

- `getArcadeDrawRuntime`：按游戏池、只取窗口内注单；**无**房间偏置、**无**共盘铁律、**无**控后冷却。  
- `tries` 取 `arcadeCandidateTries`（默认 3），**不再**复用共盘 `candidateTries`。  
- 目标 RTP 默认 0.92、窗口默认 14 天（均可配）；权重表在 `packages/shared`（水果机 / 奔驰宝马）。  
- 池聚合按 `gameId + createdAt` 走复合索引，Redis 缓存 10 秒、键上带窗口天数。

## 5. 偏置进度

- 结算后 `applySoftBiasProgress(touches)`，增量累计。  
- touch 必须有 `roomId` + `playerId`（来自注单 `payload.fly.roomId`）。  
- 满 `goalAmount` → `enabled=false` 并记操作日志。  
- 街机路径勿调用。  
- 开奖加载启用偏置：`listActiveBiasRefs` `take: 10`（`MAX_ACTIVE_SOFT_BIAS`），`createdAt asc`。

## 6. 配置校验（保存时）

- 目标带下限 &lt; 上限。  
- **中轴落在目标带内**。  
- 试号、缓刹倍数、街机 RTP、开盘门槛等有上下限。  
- 日账佣金估算率只读自 `RebatePolicy.totalRate`（回水规则·回水总额），不落 `GlobalSoftControl` 表。

## 7. 与旧硬控边界

- 全局软控 = 现行控奖。  
- 旧 `ControlPolicy` / 房间硬控目标回血等路径已降级或停用，勿混用两套叙事。
