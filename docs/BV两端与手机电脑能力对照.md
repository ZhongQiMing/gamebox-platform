# BV 两端 vs 我们三角色 · 电脑 / 手机能力对照

> 口径拍板：**代理按 A（对齐 BV 房主 APP），管理按 B（电脑为主、手机急办）**。  
> BV 能力来自 [bv-app.com](https://www.bv-app.com/) 与现网截图对照。

---

## 0. 角色别混

| BV 称呼 | 日常干什么 | 我们系统 |
|---------|------------|----------|
| 房主 / 群主 | 拉客、审进房、批上下分、开飞关飞 | **代理 AGENT**（含子账号 PROXY / 客服 CS 代劳） |
| 平台侧运营 | 开房、开号、全局规则 | **管理员 ADMIN / 房主 BRANCH** |

BV 官网主推「房主身份」登录 Web + APP，**不是**单独宣传平台管理员手机端。

---

## 1. BV 公开材料：同一房主号的两端分工

| 端 | BV 强调 | 一句话 |
|----|---------|--------|
| **电脑** | 完整房主后台、网页用户管理、上盘助手**设置**、上盘助手**核算**、飞单系统主页面 | 坐下来配规则、管人、对账 |
| **手机** | 群消息、进房审核、上下分申请推送、房间基础设置；也可即时飞单 | 人不在电脑前也能把生意接住 |

原则：

- 手机 = **待办推送 + 当场批 + 房间快调**
- 电脑 = **管人、上盘设置、核算、复杂配置**

---

## 2. 我们系统：按角色拆两端

### 2.1 代理 AGENT（= BV 房主）——手机是主战场

| 能力 | 电脑 `admin-panel` | 手机 `client-app/staff` |
|------|--------------------|-------------------------|
| 上下分申请待办 / 当场批 | 有（客服上下分等） | **有** `/staff/fund?type=UP\|DOWN` |
| 进房审核 | — | **有** `/staff/join`（新进房 PENDING） |
| 给玩家上下分 | 有 | **有** `/staff/players` |
| 客服聊天 | 有 | **有** `/staff/cs` |
| 收款方式 / 发码 | 有（客服桌面） | **有** `/staff/pay-methods` + 聊天发码 |
| 回水比例 | 有 | **有** `/staff/rebate`（主代理可改） |
| 本房快开关 / 房间状态 | 有 | 有（房间详情） |
| 看流水 / 报表 | 有 | 有（竞猜 / 积分 / 上下分 / 代理报表 + 资金流水） |
| 发红包 | 无 | **不做** |
| 飞盘 / 上盘设置与核算 | **为主**（开关 + 核算） | 手机 **上盘查询**：占用 + 分房状态 + 主代理整房飞盘/关盘；不做完整上盘助手核算 |

手机壳（代理 / 子账号，对齐 BV 三底栏）：

| 底栏 | 路由 | 内容 |
|------|------|------|
| **游戏大厅** | `/staff/lobby` | 选本房 → 已开游戏列表 → `play-enter` 进桌（代理身份） |
| **管理中心** | `/staff/home` | 英雄区 + 四宫格 + 扁平菜单 |
| **个人中心** | `/staff/profile` | 昵称/角色/额度、收款方式、改密、退出 |

管理中心内：

1. **英雄区**：今日盈亏 +「今日统计」→ 上分 / 下分 / 流水；脚注现金盘「上盘额度/持分」、信用盘「剩余信用/佣金账户/持分/合同」  
2. **四宫格**：申请上分 / 申请下分 / 进房审核 / 收款方式  
3. **扁平菜单**：客服聊天 → 上盘查询 → 回水 → 竞猜报表 → 积分报表 → 上下分报表 → 代理报表 → 玩家上下分 → 下级挂靠 → 资金流水  
4. 不做：发红包、福利报表、上盘助手、APP 分享、单独「经营报表」  

子页：申请记录 `/staff/fund`、竞猜报表 `/staff/report?view=guess`、代理报表 `/staff/agents`（团队盈亏+玩家流水榜，不是子账号列表）、下级挂靠 `/staff/hang`（给玩家挂靠下级，仅主代理）、收款方式 `/staff/pay-methods`、改密 `/staff/password`。

### 2.2 管理员 ADMIN / 房主 BRANCH——电脑为主，手机急办

| 能力 | 电脑 | 手机 |
|------|------|------|
| 建房 / 绑代理 / 账号中心 | **全量** | 不做 |
| 给代理划拨 / 回收额度 | 有（现金盘上下分；信用盘调信用额度） | **快操作**（现金房上下分；信用房进房间调额度） |
| 房间营业状态 / 开关游戏 | 有 | **快操作**（进房间） |
| 今日盈亏一眼 | 有 | **首页 KPI** |
| 经营报表细拆 / 导出 | **全量** | 摘要 |
| 风控告警处理 | 有 | **待办入口** |
| 操作日志细查 | **全量** | 手机不做入口 |
| 游戏管理 / 控奖（仅 ADMIN） | **全量** | 不做 |
| 回水政策 | **全量** | 不做（全局规则） |

## 3. 和现状的差距（便于回归）

| 问题 | 应对 |
|------|------|
| 曾把电脑菜单缩成手机五入口，点进去像空壳 | 管理手机改为待办 + 快操作 |
| 代理手机与管理手机混用同一心智 | 代理首页独立 BV 式四宫格 |
| 角色名「房主」在 BV=群主、在我们=BRANCH | BRANCH 称「房主」，AGENT 称「代理」 |
| 进房曾即进即批 | 现改为 PENDING，代理手机审 |

## 4. 明确不做 / 电脑端

- 发红包 / 福利报表 / APP 分享（无产品模型）  
- BV 完整上盘助手设置 / 核算页（手机仅上盘查询；开关在电脑）  
- 完整用户管理、开子账号完整流（引导电脑）
