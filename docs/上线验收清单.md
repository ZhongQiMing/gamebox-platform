# 上线验收清单（App 逐游戏）

> 原则：钱与中奖只认服务端；注单核对右侧是投注合计不是赢钱；大厅无假开奖号。

## 通用（每个房间游戏）

- [ ] 进房余额 = 大厅余额；下注扣款即时；刷新后一致
- [ ] 封盘 → 注单核对金额 = 各注合计（右侧不是赢钱）
- [ ] 开奖动画号码 = 结果卡 = 顶部历史最新一期
- [ ] 中奖核对只出现真实命中；未中机器人/真人不上榜
- [ ] 「您本期」输赢 = 服务端注单合计
- [ ] 杀进程重进：同一期不重复推封盘/注单/结果/中奖卡
- [ ] 面板赔率 = 管理端 pay-table
